    시작하기¶

    기준일: 2026-10-28 · 근거: 공식 문서

    한눈에 보기¶

    Databricks를 처음 쓰는 방법은 세 가지입니다. Free Edition 으로 개인 학습을 하거나, 무료 체험판(free trial) 으로 업무 평가를 하거나, 조직이 이미 가진 워크스페이스에 들어가는 것입니다. 공식 시작하기 페이지는 계정이 없으면 무료 체험에 가입하라고 안내합니다.

    경로 대상 기간 클라우드 계정 필요 여부
    Free Edition 개인 학습, 교육, 비상업적 목적 상시 무료이며 일일 사용 한도가 있음 공식 문서에 명시 없음 (클래식 컴퓨트를 쓸 수 없음)
    무료 체험판(free trial) 업무 평가, 상업적 POC 가입 후 14일 동안 크레딧 사용 익스프레스 가입은 이메일로 시작할 수 있음. 클래식 워크스페이스는 고객 AWS 계정 리소스를 사용
    기존 워크스페이스 회사에서 이미 운영 중인 환경 조직 계약에 따름 조직 설정에 따름

    참고 이 페이지의 조건과 한도는 2026-10-28 기준 공식 문서 원문을 옮긴 것입니다. 가입 화면과 조건은 바뀔 수 있으므로 가입 전에 원문을 다시 확인하십시오.

    1. 세 경로 비교¶

    공식 문서의 Free trial과 Free Edition 비교 페이지를 옮기면 다음과 같습니다.

    항목 무료 체험판 Free Edition
    목적 비즈니스 평가를 위한 전체 플랫폼 접근 개인용으로 제공되는 플랫폼의 제한 버전
    기간 크레딧은 시작 후 14일 동안 유효합니다. 상시 무료이며 일일 한도가 있습니다.
    비용 크레딧 제공 (금액은 가입 페이지 확인) 결제 없이 사용
    용도 상업적 사용 포함, 독점 데이터 연결 POC 가능 학습, 교육, 기타 비상업적 목적
    컴퓨트 클래식 워크스페이스를 포함한 전체 플랫폼 서버리스 워크스페이스 1개. 클래식 컴퓨트 접근 불가
    컴퓨트 한도 원문에 명시 없음 컴퓨트 크기와 사용량이 제한됨
    이메일 업무용 이메일 권장 개인 이메일
    체험 후 신용카드, 마켓플레이스, 약정 계약 중 선택해 결제 전환 해당 없음
    기능 운영 계정, 다중 워크스페이스, 선택적 강화 규정 준수 제어 일부 기능이 잠겨 있음(잠긴 기능 목록은 별도 페이지)

    주의 Free Edition은 클래식 컴퓨트에 접근할 수 없습니다. 클래식 워크스페이스 아키텍처, 워크스페이스 버킷, 고객 VPC 연결을 실습하려면 무료 체험판의 클래식 워크스페이스나 조직 워크스페이스가 필요합니다.

    2. 무료 체험판 가입 경로¶

    공식 시작하기 페이지는 두 가지 가입 경로를 설명합니다.

    경로 시작 방법 결과
    익스프레스 설정(Express setup) 이메일 주소로 가입 서버리스 워크스페이스가 생성됩니다. 나중에 고객 AWS 계정에 클래식 워크스페이스를 추가할 수 있습니다.
    AWS Marketplace 기존 AWS 계정으로 체험 시작 서버리스 워크스페이스를 바로 받습니다. 클래식 워크스페이스도 고객 AWS 계정의 리소스로 만들 수 있습니다. 체험 종료 후에는 AWS 콘솔을 통한 종량제(pay-as-you-go)로 전환됩니다.

    체험 중 관리¶

    • 워크스페이스 상단바의 Manage trial 버튼에서 남은 크레딧을 보거나 업그레이드할 수 있습니다.
    • 업그레이드하면 전체 플랫폼 접근이 열리고, 남은 크레딧은 그대로 이월됩니다.

    체험 한도 (개인 이메일 계정 기준)¶

    공식 문서는 개인 이메일 계정에 다음 한도가 적용된다고 설명합니다. 업무용 이메일을 쓰면 이 한도가 적용되지 않는다고 문서가 명시합니다.

    항목 한도
    SQL 웨어하우스 워크스페이스당 1개, 최대 50 DBU/시간 규모까지 확장
    서버리스 컴퓨트 (노트북, 잡, Lakeflow 파이프라인) 최대 50 DBU/시간 규모까지 확장
    GPU 사용 불가 (CPU만 사용)
    AI Search 엔드포인트 1개, 검색 유닛 1개로 제한
    외부 네트워크 접근 제한적. 차단된 데이터셋은 볼륨에 수동 업로드해야 할 수 있음
    기타 일부 기능이 제한되거나 사용할 수 없을 수 있음

    체험 종료 방법¶

    주의 체험을 취소하기 전에 모든 컴퓨트를 종료하고 결제 정보를 삭제 하십시오. 공식 문서는 그렇게 하지 않으면 크레딧이 소진된 뒤 계정이 종량제로 전환된다고 설명합니다.

    3. Free Edition으로 시작하기¶

    Free Edition은 별도 클라우드 계정이 없어도 서버리스 워크스페이스로 시작할 수 있습니다. 시작 순서는 다음과 같습니다.

    1. Free Edition 가입 페이지에서 개인 이메일로 가입합니다. 가입 절차는 공식 시작하기 페이지와 Free Edition 페이지의 최신 안내를 따르십시오.
    2. 워크스페이스에 로그인합니다. 홈 화면과 사이드바 구성은 워크스페이스 UI를 참고하십시오.
    3. Workspace 항목에서 노트북을 하나 만듭니다.
    4. 노트북에 %sql 셀로 간단한 쿼리를 입력하고 Shift+Enter로 실행합니다. 노트북 셀 사용법은 노트북 기초를 참고하십시오.
    5. 예제 데이터를 쓰거나 CSV를 가져와 테이블을 만듭니다. 아래 튜토리얼 목록에서 해당 실습을 고릅니다.
    -- 첫 실행 확인용 쿼리: 현재 사용자와 현재 카탈로그를 확인합니다.
SELECT current_user() AS me, current_catalog() AS catalog_name;

    참고 current_user()와 current_catalog()는 Databricks SQL 함수입니다. 결과 값에는 본인의 사용자 정보가 나타나므로, 화면을 캡처해 공유할 때는 이메일 주소를 가리십시오.

    4. 공식 튜토리얼 순서¶

    공식 시작하기 페이지는 튜토리얼을 영역별로 나누어 제공합니다. 이 교육 자료는 아래 순서를 권장합니다.

    순서 영역 튜토리얼 공식 경로
    1 데이터 탐색 쿼리와 시각화 (Query and visualize data) /aws/en/getting-started/quick-start
    2 데이터 탐색 노트북에서 CSV 가져와 시각화 /aws/en/getting-started/import-visualize-data
    3 데이터 탐색 테이블 만들기 (Create a table) /aws/en/getting-started/create-table
    4 데이터 탐색 Genie One에서 대시보드와 데이터 탐색 /aws/en/getting-started/analyst-get-started
    5 데이터 엔지니어링 Lakeflow pipelines로 ETL 파이프라인 만들기 /aws/en/getting-started/data-pipeline-get-started
    6 데이터 엔지니어링 Apache Spark로 ETL 파이프라인 만들기 /aws/en/getting-started/etl-quick-start
    7 AI·머신러닝 모델 학습과 배포 /aws/en/getting-started/ml-get-started
    8 AI·머신러닝 딥러닝 모델 학습과 추적 /aws/en/mlflow/mlflow3-dl-workflow
    9 AI·머신러닝 노코드로 LLM 질의와 에이전트 프로토타입 /aws/en/getting-started/gen-ai-llm-agent

    참고 튜토리얼 제목에 나오는 Genie One은 공식 시작하기 페이지의 표기입니다. 다른 페이지의 Genie 명칭(Genie Agents, Genie Code)과 역할이 다르므로 혼동하지 마십시오. 자세한 구분은 용어 정리에서 다룹니다.

    5. 막혔을 때¶

    증상 확인할 것
    컴퓨트가 시작되지 않는다 Free Edition은 클래식 컴퓨트를 쓸 수 없습니다. 노트북의 컴퓨트 선택이 서버리스인지 확인하십시오.
    특정 기능 메뉴가 잠겨 있다 사이드바의 자물쇠 아이콘은 권한이 없다는 뜻입니다. 체험 한도 또는 워크스페이스 권한을 확인하십시오.
    외부 데이터 소스에 접속되지 않는다 체험 한도에 외부 네트워크 접근 제한이 있습니다. 파일을 볼륨에 업로드하는 방법을 쓰십시오.
    노트북 셀 결과가 예상과 다르다 런타임 버전에 따라 셀 실행 방식(개별 또는 배치)이 다릅니다. 노트북 기초를 확인하십시오.
    공식 지원이 필요하다 공식 지원 페이지(/aws/en/resources/support)와 Databricks Community를 참고하십시오.

    6. 트레이드오프와 주의사항¶

    선택 장점 한계
    Free Edition 비용 없이 서버리스 기능을 익힐 수 있습니다. 클래식 컴퓨트, 상업적 사용, 대규모 데이터 실습에 맞지 않습니다.
    무료 체험판 클래식 워크스페이스까지 실습할 수 있습니다. 14일 기간이 있고, 체험 종료 전 결제 정보 설정을 확인해야 합니다.
    기존 워크스페이스 실제 데이터와 권한 체계를 쓸 수 있습니다. 관리자 권한과 조직 정책의 제약을 받습니다.

    주의 학습용 계정에 실제 고객 데이터나 회사 기밀 데이터를 올리지 마십시오. Free Edition은 학습과 비상업적 목적을 전제로 합니다.

    주의 체험 기간 종료 후 과금이 시작되지 않도록, 사용하지 않는 컴퓨트를 종료하고 결제 정보 설정을 확인하는 습관을 들이십시오.
